# 🕷️ SEO-Diver Web Crawler & Audit Tool

An automated technical SEO auditing engine and dashboard built with Python, aiohttp, and Streamlit.

## Features
- Async high-throughput crawl engine with per-host polite delays & anti-WAF jitter.
- Multi-host XML sitemap discovery and robots.txt evaluation.
- Duplicate title, H1, and content detection via DOM normalization.
- In-memory multi-tab Excel (.xlsx) export.
